Specimen

Aura.Sql is PDO with the sharp edges filed off — the same object you already know, plus array binding, lazy connections and a profiler.

Because it extends PDO, existing code that uses PDO keeps working unchanged.

use Aura\Sql\ExtendedPdo;

$pdo = new ExtendedPdo('sqlite::memory:');

$posts = $pdo->fetchAll(
    'SELECT * FROM posts WHERE id IN (:ids) AND status = :status',
    [
        'ids'    => [1, 2, 3],   // arrays bind as lists
        'status' => 'published',
    ]
);

foreach ($pdo->yieldAssoc('SELECT id, title FROM posts') as $id => $row) {
    echo $id . ': ' . $row['title'] . PHP_EOL;
}
